## Security proof and risk

The removed description bypass was exploitable by ordinary accounts uploading to tagged pages, across three sibling write paths. A database-backed HTTP regression created an approved game/event with `[DEMO_MATCHUP]` and sent uploads without location. Before the fix, `/posts` and game stories returned **201**. After the fix, posts and both story routes return **403**. The blast radius was event posting integrity; the route fix is reversible, while previously created content requires separate review.

The privacy regression creates public, blocked, and private authors plus four past events. An authenticated discovery request exposes only the event with a visible public post, sets its gold-pin flag, and retains all four database records. No separate, weaker privacy mechanism was introduced.
